# App icon

The icon is an orbital C with six segments around a central point: a day at the center of its surrounding week. The simple silhouette, generous inset, text-free composition and restrained blue/teal palette are intended to read at small sizes. The app keeps its monochrome SF Symbol in the menu bar, where a full-color app icon would be distracting.

Generated with the built-in image-generation tool, then packaged into standard macOS ICNS representations using sips and iconutil. Source: `Assets/AppIcon-source.png`; application resource: `Assets/AppIcon.icns`. The legacy ICNS format supports our macOS 14 minimum; this is not a layered Liquid Glass Icon Composer asset.

Guidance: [Apple app icons](https://developer.apple.com/design/human-interface-guidelines/app-icons), [Apple menu bar guidance](https://developer.apple.com/design/human-interface-guidelines/the-menu-bar).

Generation prompt:

> Create a production macOS app icon for Codex Pace, an independent app that helps ration AI inference evenly through seven days. Use case: logo-brand. One single icon, square 1024x1024 composition. Creative concept: a calm orbital dial formed by exactly seven substantial softly rounded luminous glass segments circling a small central pearlescent point; subtly suggest both a C and steady progress, no needle, no numbers. Deep midnight indigo rounded-square macOS icon tile with restrained blue-to-teal glass highlights, clean dimensional layers, crisp silhouette and simple large geometry legible at 32 pixels. Straight-on centered view, generous consistent inset around the orbital mark. Tile fills about 88 percent of the square canvas with standard macOS rounded corners, actual transparent background outside the tile, no opaque white background. Polished Apple-platform sensibility, subtle internal depth, no dramatic cast shadow, no excessive glints or tiny ornament. No text, no letters, no branding, no OpenAI logo, no mockup device, no surrounding scene. Deliver only the isolated icon.

The selected result interprets this as six orbital segments plus the center, seven elements in total.
